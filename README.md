
# Python Data Analysis with NumPy and Pandas

## Overview

This repository contains hands-on Python exercises covering fundamental data analysis operations using **NumPy** and **Pandas**. It explores numerical array operations, Series manipulation, and DataFrame-based data exploration using sample temperature and transaction datasets.

## Topics Covered

### 1. NumPy
- Creating and inspecting 1D and 2D arrays
- Checking array shape, data type, and number of elements
- Performing arithmetic operations and statistical calculations
- Converting temperatures from Celsius to Fahrenheit
- Array indexing and slicing

### 2. Pandas Series
- Creating Series with custom index labels
- Accessing elements using `loc` and `iloc`
- Filtering values using Boolean masks
- Updating and removing Series entries
- Performing operations on Series values

### 3. Pandas DataFrame
- Creating DataFrames from structured data
- Exploring data using `head()`, `tail()`, `shape`, `columns`, `dtypes`, and `info()`
- Selecting columns and filtering rows
- Finding value counts and unique values
- Grouping data and calculating mean values
- Updating values, adding columns, and deleting rows or columns

## Technologies Used

- Python
- NumPy
- Pandas
- Jupyter Notebook

## Installation and Setup

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <repository-folder>
   ```

3. Install the required libraries:

   ```bash
   pip install numpy pandas jupyter
   ```

4. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

## Datasets

The exercises use sample datasets involving:
- Daily average temperatures recorded over two weeks.
- Student marks with custom rank labels.
- Transaction records containing transaction IDs, product categories, regions, and amounts.

## Learning Outcomes

- Understanding NumPy arrays and numerical computations.
- Working with Pandas Series and DataFrames.
- Performing data selection, filtering, and manipulation.
- Applying grouping and aggregation operations.
- Developing fundamental skills in Python-based data analysis.
